# App Store submission assets

Not bundled into the app — these are marketing/submission assets for App Store Connect.

- `APP-REVIEW-GUIDE.md` — paste-ready App Review Information notes, the full permissions
  table, and a pre-empted-rejection-reasons table (format borrowed from the MiLuv project's
  `docs/RELEASE.md`). Read this before submitting.
- `SCREEN-RECORDING-GUIDE.md` — a shot-by-shot script for the demo video to attach with the
  review notes, proving the alarm survives a real force-quit at full volume through Silent
  mode, and that the new Record Your Own Alarm Sound feature never leaves the device.

## Screenshots

All images are 1320×2868 (Apple's required "6.9-inch Display" size).

- `screenshots-6.9-raw/` — actual device screenshots of the real app (onboarding + a real
  ringing screen), already at the correct resolution as captured.
- `promo-6.9/` — original promotional graphics for the App Store product page, built from the
  app's real logo, icon set, and theme colors (not screenshots) — a brand/welcome slide, Smart
  Wake Window explainer, sleep-science hook, smart-features overview, the 6 dismiss missions,
  a reliability/hard-deadline slide, a fixed-time-vs-Smart-Wake comparison, and a Record Your
  Own Alarm Sound slide.

Upload whichever set (or mix) you prefer to App Store Connect's 6.9" Display screenshot slot.
App Store Connect only strictly requires screenshots for the largest size in the iPhone
family (6.9") — it's generally used to auto-fill smaller size slots (6.5", 6.1", etc.) if you
don't upload device-specific captures for those, though it's worth double-checking that's
still current behavior when you're actually in App Store Connect submitting.
